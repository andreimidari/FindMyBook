# Plugin-store manifest entry

This folder stages the entry for
[Flow-Launcher/Flow.Launcher.PluginsManifest](https://github.com/Flow-Launcher/Flow.Launcher.PluginsManifest).

To publish the plugin in the Flow Launcher store:

1. Fork the manifest repository.
2. Copy `FindMyBook-de485b1f-be4a-4fda-bc3d-cdf9aa6ca801.json` into its `plugins/` folder.
3. Update `Version`, `UrlDownload`, and `IcoPath` if needed.
4. Open a pull request.

See [RELEASING.md](../RELEASING.md) for the full release checklist.
